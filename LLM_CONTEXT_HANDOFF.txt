=================================================================
1) EXECUTIVE SUMMARY & ACTIVE PROJECTS
=================================================================

GameKing is a multi-project web platform with an animated retro portal homepage.
The project grid on the homepage features 7 circular cards:
1. Circle 1: Tic-Tac-Toe (/tictactoe, /tictactoe.html)
   - Singleplayer vs AI and real-time multiplayer with matchmaking queue & in-memory room state.
2. Circle 2: Before GTA 6 (/beforegta6, /beforegta6.html)
   - Community meme tracker with category badges, up/down voting, submission modal, and persistent SQLite database.
3. Circle 3: Dashy by TNH (/dashy, /dashy.html)
   - Internal operations dashboard for GameKing in Pokhara, Nepal.
   - Zero-framework vanilla stack: Nepali BS calendar (2080-2086), staff PIN attendance, weekly roster, cleaning schedule, vendor ledger (currency in Rs).
4. Circles 4–7: Reserved placeholder slots for future games/tools.

The project operates in two primary environments:

A) Local full-stack development mode (Flask server)
- Runs with: python app.py (default port: 5000)
- Serves dynamic templates from templates/ and assets from static/.
- Serves both clean routes (/, /tictactoe, /beforegta6, /dashy) and .html aliases (/tictactoe.html, /beforegta6.html, /dashy.html).
- Handles backend APIs: Before GTA 6 persistent storage & voting, Tic-Tac-Toe matchmaking and room state.

B) Production static mode on Netlify
- Netlify does NOT run Flask app.py.
- Netlify runs build command: python netlify_build.py
- Netlify publishes directory: dist/
- netlify.toml configures 200 rewrites for /tictactoe, /beforegta6, /dashy.

C) Local static preview mode
- Runs with: python netlify_build.py && python -m http.server 8000 --directory dist
- Used to test raw static output as Netlify will serve it.

=================================================================
3) ROUTING CONTRACT (FLASK VS NETLIFY)
=================================================================

To prevent broken links across both environments:

In templates/index.html:
- Circle 1 links to /tictactoe.html
- Circle 2 links to /beforegta6.html
- Circle 3 links to /dashy

In app.py (Flask):
- @app.route('/')
- @app.route('/tictactoe', strict_slashes=False) + @app.route('/tictactoe.html')
- @app.route('/beforegta6', strict_slashes=False) + @app.route('/beforegta6.html')
- @app.route('/dashy', strict_slashes=False) + @app.route('/dashy.html')

In netlify.toml (Netlify):
- Redirect /tictactoe -> /tictactoe.html (status = 200)
- Redirect /beforegta6 -> /beforegta6.html (status = 200)
- Redirect /dashy -> /dashy.html (status = 200)

Result: Both clean URLs and .html URLs work seamlessly in both local Flask and production Netlify.

=================================================================
4) INCIDENT HISTORY & RESOLUTIONS
=================================================================

Incident 1: Plain-text unstyled page in production
- Cause: Templates used relative paths (../static/...) and publish directory was missing.
- Fix: Converted all asset links to root-absolute (/static/...) and created netlify_build.py to generate dist/.

Incident 2: 404 Not Found when clicking circles 1–3 in Flask
- Cause: index.html links had .html extensions (/tictactoe.html, /beforegta6.html) and /dashy, which worked on static servers but Flask only had clean routes (/tictactoe, /beforegta6) and lacked a /dashy route.
- Fix: Added dual route decorators in app.py for clean paths and .html paths, plus /dashy and /dashy.html.

=================================================================
5) NON-NEGOTIABLE DEVELOPMENT RULES
=================================================================

Rule 1: Never edit dist/ or dashy/deploy/ directly.
- Always edit templates/, static/, or dashy/ source files, then run python netlify_build.py.

Rule 2: Never use relative ../static paths in templates.
- Always use /static/... absolute paths.

Rule 3: Dashy sacred assets:
- NEVER overwrite or modify dashy/assets/dashy-icon.svg.
- Keep currency as Nepalese Rupees (Rs).
- Keep timezone synced to Asia/Kathmandu.

Rule 4: Always verify build before pushing to main:
- python netlify_build.py
- git status
